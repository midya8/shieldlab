The controller needs one safe choice. The environment must have no unsafe escape. Follow that difference until every future obligation is closed.

A tiny, fully visible protocol game. No model, API, reward function or real-system safety claim.

1. Choose who controls the next move

Every state has at least one move. Safety means never visiting a state marked unsafe, including the starting state. Waiting forever can be safe: progress is a different objective.

2. Replay the greatest fixed point

Start with all states marked safe. Keep a controller state if at least one move stays in the previous set. Keep an environment state only if every move stays there. Rounds are synchronous; the final unchanged round is included.

Every move's previous-round target

3. Inspect all winning moves and losing ranks

Winning controller moves stay inside the final winning region. A losing rank is a bound on how many moves the environment needs to force an unsafe state, despite controller choices. Rank zero means already unsafe.

The first listed winning controller move and first rank-decreasing environment move are canonical witnesses, not unique or optimal policies. All winning controller moves are shown.

4. Check the whole strategy graph

For a winning root, fix the canonical controller choices and retain every environment choice: the reachable graph is a closed safe invariant. For a losing root, fix the canonical environment choices and retain every controller choice: every edge before failure strictly decreases rank. Stop at unsafe states.

Every retained proof edge

5. Replay the complete certificate

The separate native checker computes the dual unsafe attractor and independently enumerates all positional controller policies, checking graph reachability to unsafe states. It never calls the solver. Independent JavaScript uses sets, while the native solver uses bitmasks.

Scope and attribution
One to six states, one to three uniquely named moves per state. Finite, total, deterministic moves, turn-based perfect information, adversarial environment. No probabilities, simultaneous moves, clocks, partial observation, learned abstraction, temporal-logic compiler, liveness, reward optimization or runtime enforcement.
This is an inspectable hand-written model, not a deployed shield, LLM guarantee or novel game-solving algorithm. Missing real behavior invalidates conclusions about real software.
