Safe waiting
is not arrival.

A move can stay in the winning region and still stall forever. Distinguish a possible winning continuation from a strategy that forces the goal.

Finite adversarial protocol games. The first safe goal stops the play; no fairness assumption makes the environment cooperate.

1. Decide what counts as arrival

All goals must be safe. An unsafe starting state loses immediately. After a goal is reached, its outgoing moves are irrelevant. Empty targets lose reach-avoid, even when waiting forever is safe.

2. Grow a finite arrival guarantee

Start with the terminal goals. A safe controller state needs one successor already admitted; a safe environment state needs every successor admitted. Round k adds states that can force first arrival within k+1 moves. The final unchanged round is retained.

3. A winning successor is not a progress shield

The rank is the minimum worst-case number of moves to a first goal. Optimal controller moves decrease that rank by exactly one. Other moves can have a winning successor yet permit a slower policy or endless waiting.

4. Audit the complete strategy graph

For a winning root, fix an optimal controller choice and retain every environment move: each edge strictly decreases rank until a goal. For a losing root, fix a target-avoiding environment choice and retain every controller move. Its closed trap can hit unsafe or avoid every goal forever. One sampled path alone would not prove this.

5. Inspect every positional policy

Enumerate all action assignments on safe non-goal controller states, including unreachable ones. A policy succeeds from a root only if every environment branch hits a goal before unsafe. A reachable non-goal cycle is failure, not evidence of eventual cooperation.

Boundaries before interpretation
One to six states, one to three moves per state, finite total turn-based perfect information and deterministic actions against an adversary. Goal is terminal first-hit success, not repeated visitation or safety forever after arrival. Safety-until-goal uses absorbing success; it is not necessarily the original infinite-safety objective.
Counts are action assignments, not distinct behaviors or history-dependent strategy counts. This is a tiny hand-written model inspector, not a deployed shield, fairness rule, probabilistic guarantee, continuous controller, learned abstraction, reward optimizer, temporal-logic compiler or new theorem. Missing real behavior invalidates real-system conclusions. Classical reachability sources are credited in the contract and source ledger. Original controls and code.
